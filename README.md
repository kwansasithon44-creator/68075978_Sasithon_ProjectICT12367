# 🧺โครงงานระบบจัดการร้านซักรีด (Smart Laundry System)
# จัดทำโดย: นางสาวศศิธร เสาร์ประโคน รหัส: 68075978
# รายวิชา: ICT12367 การจัดการระบบฐานข้อมูลและการประยุกต์

⚠️ Pain Points (ปัญหาหลักที่พบในปัจจุบัน)
จากปัญหาของร้านซักผ้าแบบเดิมที่พี่สรุปมา ระบบนี้ถูกออกแบบมาเพื่อแก้ปัญหาดังนี้:
- ปัญหาการรอคิว: ลูกค้าไม่รู้สถานะเครื่อง ทำให้เสียเวลามารอที่ร้านนาน
- ความกังวลด้านความปลอดภัย: ปัญหาผ้าหายหรือสลับกันระหว่างรอเอาผ้าออก
- สุขอนามัย: ความกังวลเรื่องการใช้เครื่องต่อจากผู้อื่นที่อาจไม่สะอาด
- ภาระเรื่องเหรียญ: ความยุ่งยากในการหาที่แลกเหรียญ หรือปัญหาตู้กินเหรียญ/ตู้เสีย

🛠 การทำงานของระบบ (System Workflow)
ระบบถูกแบ่งออกเป็น 2 ส่วนหลัก เพื่อให้การบริหารจัดการลื่นไหลที่สุด:

1. หน้าสำหรับลูกค้า (Customer Interface)
เน้นความสะดวกสบายและลดการรอคอยที่ร้าน:
- การจองบริการล่วงหน้า: ลูกค้าสามารถเลือกประเภทการซัก (ซักพับ/ซักรีด) และเลือกแพ็กเกจ (ปกติ/ด่วน) ได้จากที่พัก ไม่ต้องมานั่งรอที่ร้าน
- ระบบเลือกเวลา (Timeslot): สามารถระบุวันที่และเวลาที่จะส่งผ้าและรับผ้าคืนได้ ทำให้ร้านบริหารจัดการคิวเครื่องซักผ้าได้มีประสิทธิภาพมากขึ้น ลดปัญหาเครื่องไม่เพียงพอ
- ชำระเงินผ่านการสแกน: ตัดปัญหาเรื่องการหาแลกเหรียญหรือตู้หยอดเหรียญเสีย เพราะใช้ระบบ QR Code ชำระเงินตามจริง
- ระบบสะสมแต้ม: ทุกการใช้บริการจะเปลี่ยนเป็นคะแนนสะสม เพื่อใช้เป็นส่วนลดในครั้งถัดไป สร้างความรอยัลตี้ให้ลูกค้ากลับมาใช้ซ้ำ

2. หน้าสำหรับแอดมิน/พนักงาน (Admin & Staff Dashboard)
เน้นความถูกต้องและการติดตามสถานะเพื่อป้องกันผ้าหาย:
- การจัดการออเดอร์ (Order Management): พนักงานเห็นออเดอร์ที่ลูกค้าสั่งเข้ามาทันที พร้อมรหัสลูกค้าที่ชัดเจน ป้องกันการสลับผ้า
- อัปเดตสถานะ Real-time: พนักงานจะคอยกดอัปเดตสถานะ (รับผ้าแล้ว -> กำลังซัก -> เสร็จแล้ว -> ส่งมอบแล้ว) ลูกค้าสามารถเช็คได้จากระบบว่าผ้าถึงขั้นตอนไหน ไม่ต้องเดาเวลาเอง
- สรุปรายได้และสถิติ: ระบบช่วยรวบรวมยอดขายรายวันและรายเดือน เพื่อให้เจ้าของร้านเห็นภาพรวมของธุรกิจได้ชัดเจน

✅ สรุปผลลัพธ์ของระบบ
ระบบนี้เปลี่ยนจากการที่ลูกค้าต้อง "แบกผ้ามาเสี่ยงดวงที่ร้าน" เป็นการ "นัดหมายและเตรียมการล่วงหน้า" ซึ่งช่วยลดปัญหาผ้าหายได้ 100% เพราะมีพนักงาน (อย่างเช่น พี่มาลี E001) คอยดูแลจัดการเครื่องและแยกผ้าให้เป็นระเบียบตามรหัสออเดอร์นั่นเองค่ะ
